Day 1 — Tinglish Quick Notes

## 🇮🇳 Tinglish Explanations\n\n### Cybersecurity\nCybersecurity ante systems, applications, networks, identities, and data ni unauthorized access, modification, destruction, or disruption nunchi protect cheyadam.\n\n### CIA Triad\n- **Confidentiality** → Evaru data chudagalru?\n- **Integrity** → Evaru data ni change cheyagalru?\n- **Availability** → Required time lo system available ga unda?\n\nEasy memory: **Confidentiality = See, Integrity = Change, Availability = Use.**\n\n### Authentication vs Authorization\n- **Authentication** → “Nuvvu evaru?” Identity verify cheyadam.\n- **Authorization** → “Nuvvu em cheyagalavu?” Permissions decide cheyadam.\n\nExample: Login successful avvadam authentication. Login ayyaka admin-only page access cheyagalava leda ani decide cheyadam authorization.\n\n### Encryption vs Hashing\n- **Encryption** → Key use chesi data ni protect chestam; correct key tho decrypt cheyochu.\n- **Hashing** → Data ni one-way hash value ga convert chestam; passwords kosam Argon2/bcrypt/scrypt lanti password-hashing algorithms use chestaru.\n\n### Security Mindset\nApplication work avtunda ani matrame kakunda: “Evaru access cheyagalru?”, “Attacker ki access vaste em cheyagaladu?”, “Em data expose avtundi?” ani think cheyali.\n\n### 🎤 Interview Memory\n- Authentication = **Who are you?** / **Nuvvu evaru?**\n- Authorization = **What can you do?** / **Nuvvu em cheyagalavu?**\n- CIA = **See, Change, Use**
